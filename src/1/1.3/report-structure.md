## 1.3 Report Structure

This report is organised into six main chapters, followed by appendices:

**Chapter I: Introduction** provides the background and motivation for this project, defines its scope and objectives, and outlines the structure of the report.

**Chapter II: Background — LLM-Assisted Development and Vibe Coding** establishes the conceptual foundations of the work. It introduces large language model architectures and inference workloads, surveys the landscape of LLM-assisted coding tools including GitHub Copilot, and discusses the emerging practice of vibe coding — its promises, its limitations, and the software engineering discipline needed to use it effectively.

**Chapter III: Application Design and Architecture** documents the design process for the LLM-integrated web application. It covers the requirements analysis, system decomposition, choice of Llama 3.2 and Ollama as the inference backend, frontend and backend architecture decisions, and the role of the AI assistant in shaping those decisions.

**Chapter IV: LLM-Assisted Implementation** describes the development process in detail. It covers how GitHub Copilot was used to generate the application's components, how prompts were structured and iterated, where the AI produced correct and useful output, and where human intervention was necessary to correct, redirect, or refine the generated code.

**Chapter V: Evaluation and Findings** assesses the outcomes of the project. It evaluates the functional quality of the resulting application, analyses the vibe coding workflow against traditional development practices, and reflects on system design tradeoffs encountered during LLM-assisted construction.

**Chapter VI: Conclusion and Future Work** summarises the key findings from both the application and the development process, offers recommendations for practitioners considering vibe coding, and identifies directions for further research.

**Appendices** include selected code examples, system diagrams, and references to research resources consulted during the project.
