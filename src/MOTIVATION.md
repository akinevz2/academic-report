# Motivation

Various tools exist in the space of note-taking, note-organisation, documentation-writing. Few of these tools have managed to successfully leverage the LLM economy from the point of collaborative editing with aidance from the LLMs.

Our motivation for this project comes directly from the point of view that a creative block, writers paralysis, demotivation and low mood which can directly affect the cadence of a written project, but can be tackled with the power of a carefully engineered software.

This project aims to fill this gap by developing a suite of tools that can be integrated into, or be used to build a note-taking application from the ground up, or to serve as a framework for specifying a toolkit in future work.
