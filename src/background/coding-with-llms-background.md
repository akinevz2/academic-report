# 3. Coding with LLMs - Background {#background}

## The Role of LLMs in Software Development
Large Language Models (LLMs) have revolutionized software development by enabling tasks such as code generation, bug detection, documentation, and natural language to code translation. Their ability to understand and generate human-like text has made them invaluable tools for modern engineering workflows.

## Key Capabilities of LLMs in Coding
- **Code Generation**: LLMs can produce functional code snippets or entire modules based on natural language descriptions.
- **Debugging Assistance**: They can identify potential bugs, suggest fixes, and explain error messages.
- **Documentation**: LLMs automate the creation of API documentation, comments, and technical write-ups.
- **Refactoring**: They assist in restructuring code for improved readability and maintainability.

## Integration with Engineering Workflows
LLMs are increasingly being integrated into development pipelines through tools like GitHub Copilot, which provides real-time suggestions during coding. This report explores how such technologies enhance productivity while maintaining traditional software engineering principles.
