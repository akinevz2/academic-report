## Report Structure

This report comprises three phases: foundational context, design planning, and outcomes. The Introduction frames the research questions and the value proposition of evidence-grounded project inspection through natural-language workflows. Background contextualises LLMs, agentic coding, and known reliability constraints from current literature. Project Description outlines the problem domain, functional requirements, and the evaluation protocol used to analyse agentic model behavior in this implementation context.

Implementation and outcome sections ground design in practice. Project Architecture describes the layered backend, frontend signal-based orchestration, persistence strategy, and tool-calling boundaries that shape agentic behavior. Implementation Timeline provides a Gantt overview of planned development phases and delivery shifts. Results and Discussion present observed outcomes, scenario-level analysis, validity threats, and gaps between intended design and delivered artefact, distinguishing measured findings from interpretation. The conclusion closes each objective strand against available evidence and identifies prioritized next steps.
