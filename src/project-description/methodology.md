## Methodology

Structured approach of traditional software engineering practices with LLM-assisted development was employed:

1. Requirements analysis and system design using markdown
2. LLM-assisted code generation for core components using tooling available within Visual Studio Code
3. Integration testing and iterative refinement through use of the Firefox desktop browser
4. Exploration of features that the agentic coding ai exposes during its use
5. Documentation of the development process and missing features
